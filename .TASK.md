## Проект: `rfast-find` (CLI-утилита)

### Цель

Создать консольную программу, которая рекурсивно ищет заданную строку в файлах указанной директории и выводит результаты с указанием пути, номера строки и её содержимого.

### Технический стек (что нужно изучить и применить)

* **`clap` (v4)**: для парсинга аргументов командной строки.
* **`anyhow`**: для удобной обработки ошибок в приложении.
* **`walkdir`**: для эффективного рекурсивного обхода папок.
* **`rayon`**: для параллельной обработки файлов (это "киллер-фича" Rust).
* **`colored`**: для красивого вывода результатов в терминал.

---

### Функциональные требования

1. **Аргументы командной строки:**
* `pattern` (обязательный): строка, которую ищем.
* `path` (опциональный): путь к директории (по умолчанию — текущая `.`).
* Флаг `-i` (`--ignore-case`): поиск без учета регистра.
* Флаг `-n` (`--line-number`): выводить номер строки.


2. **Вывод:**
* Путь к файлу должен быть выделен одним цветом, номер строки — другим, а само совпадение в тексте — третьим.
* Программа должна корректно обрабатывать файлы, которые нельзя прочитать (пропускать их и выводить предупреждение в `stderr`).



---

### Этапы реализации (Твое пошаговое руководство)

#### Этап 1: Скелет и аргументы

Настрой `Cargo.toml` и опиши структуру аргументов с помощью `clap`. Добейся того, чтобы программа принимала паттерн и печатала его.

#### Этап 2: Последовательный поиск

Реализуй логику поиска в одном потоке.

* Используй `walkdir` для получения списка всех файлов.
* Отфильтруй только текстовые файлы (или просто пытайся читать всё как UTF-8).
* Используй `BufReader` для эффективного построчного чтения.

#### Этап 3: Обработка ошибок

Вместо `unwrap()` везде используй `?` и возвращай `anyhow::Result<()>`. Сделай так, чтобы при отсутствии доступа к папке программа не паниковала, а вежливо сообщала об этом.

#### Этап 4: Параллелизм (Уровень "Rustacean")

Замени обычный итератор на параллельный итератор из библиотеки `rayon`.

* В Go ты бы создавал `WaitGroups` и каналы.
* В Rust с `rayon` достаточно заменить `.iter()` на `.par_iter()`. Почувствуй разницу в том, как Rust гарантирует безопасность данных при этом.

---

### Критерии "правильного" кода (Code Review Check-list)

* [ ] **No Global State:** Никаких глобальных переменных.
* [ ] **Ownership:** Ты передаешь `&str` там, где не нужно владение, и `PathBuf` там, где оно необходимо.
* [ ] **Idiomatic Iterators:** Вместо циклов `for i in 0..len` ты используешь `.lines()`, `.enumerate()` и `.filter()`.
* [ ] **Performance:** Программа не вычитывает весь файл в память целиком (используй построчное чтение).

### Бонусное задание (для продвинутых)

Добавь поддержку **регулярных выражений** с помощью библиотеки `regex`. Это потребует от тебя понимания того, как хранить скомпилированное регулярное выражение в памяти один раз и использовать его во всех потоках (подсказка: `Arc` или `OnceCell`).
